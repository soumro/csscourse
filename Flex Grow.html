📈 CSS `flex-grow`

Controls how flex items expand to fill extra space in the main axis.

📖 How `flex-grow` Works

  • flex-grow defines how much of the remaining space in the flex container an item should take.
  • Default value is 0 – the item does NOT grow.
  • If all items have flex-grow: 1, they share the remaining space equally.
  • If items have different values (e.g., 1, 2, 1), the extra space is distributed proportionally.
  • Only works if there is extra space after laying out the items' initial sizes (based on flex-basis or content).
  • flex-grow is a unitless number – ratios matter, not absolute values.
/* Example: 1:2:1 ratio */
.item1 { flex-grow: 1; }
.item2 { flex-grow: 2; } /* gets twice the extra space of item1 */
.item3 { flex-grow: 1; }

🧩 Flex‑Grow in Context: The `flex` Shorthand

flex-grow is part of the flex shorthand: flex: <flex-grow> <flex-shrink> <flex-basis>;

  • flex: 1; → flex-grow: 1; flex-shrink: 1; flex-basis: 0%;
  • flex: 0 1 auto; → default (no grow, can shrink, basis auto).
  • flex: 2 1 100px; → grow twice as much, can shrink, start from 100px basis.
🔥 Common pattern: flex: 1; on all items to create equal‑width columns.
