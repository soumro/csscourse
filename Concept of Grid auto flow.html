📖 What is grid-auto-flow?

The grid-auto-flow property controls how auto‑placed grid items are inserted into the grid. It defines the direction (row or column) and optionally the packing algorithm (dense).

🎯 Values Explained

ValueDirectionPackingUse Case
rowFill rows first (left to right, top to bottom)NormalDefault, natural document flow.
columnFill columns first (top to bottom, left to right)NormalVertical‑first layouts (e.g., masonry‑like).
row denseRows firstDense (fill holes)Pack items tightly, even if reorder.
column denseColumns firstDensePack vertically, fill gaps.
💡 Dense packing tries to fill any empty cells earlier, which may change the visual order of items (good for galleries, bad for tab order).
