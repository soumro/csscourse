4. Important Notes & Pitfalls

  • 🔹 Containing block for absolute: It's the nearest ancestor with position: relative/absolute/fixed/sticky. If none, it's the initial containing block (usually <html>).
  • 🔹 Fixed elements are removed from flow: They ignore scroll of the page. Use z-index to layer properly.
  • 🔹 Sticky requires a threshold (top/right/bottom/left) to activate.
  • 🔹 Percentages in offsets refer to the containing block's dimensions (for absolute) or element's own dimensions (for relative).
  • 🔹 Overflow and position: An element with overflow: hidden can clip absolutely positioned children if the child's containing block is that element.
  • 🔹 Stacking context: z-index values only compare within the same stacking context. Creating a new stacking context (e.g., position: relative; z-index: 0) isolates layers.
