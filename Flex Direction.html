📖 Understanding the Main Axis

flex-direction determines the main axis – the direction along which flex items are placed. It also affects justify-content (main axis alignment) and align-items (cross axis alignment).

  • row → main axis = horizontal (left to right)
  • row-reverse → main axis = horizontal (right to left)
  • column → main axis = vertical (top to bottom)
  • column-reverse → main axis = vertical (bottom to top)
🎯 When you change flex-direction, the meaning of justify-content and align-items swaps accordingly. For example, in column, justify-content aligns items vertically.
