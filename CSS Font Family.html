🖥️ 2. System Font Stack (Native & Fast)

This text uses the system font stack – it matches the OS default interface font.

font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif;
✅ Great performance, no external requests, and looks native on each platform.

📁 4. Self‑Hosted Fonts with @font-face

You can host font files (woff2, woff, ttf) on your server and define them with @font-face.

@font-face {
  font-family: 'MyCustomFont';
  src: url('fonts/custom.woff2') format('woff2'),
       url('fonts/custom.woff') format('woff');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
🔁 font-display: swap ensures text remains visible while the font loads, improving user experience.

✅ Best Practices & Tips

  • 🔹 Always end with a generic family (serif, sans-serif, monospace, etc.)
  • 🔹 Quote font names with spaces → "Times New Roman"
  • 🔹 Use system fonts for better performance and native look.
  • 🔹 Limit the number of custom fonts to avoid slow page loads.
  • 🔹 Use font-display: swap with web fonts to prevent invisible text (FOIT).
  • 🔹 Test fallbacks – disable fonts in DevTools to ensure your stack degrades gracefully.
  • 🔹 Combine with other font properties like font-weight, font-size, line-height for complete control.
