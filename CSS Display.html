5. display: none vs visibility: hidden

This box will be hidden with display: none (removed from layout)
This box will be hidden with visibility: hidden (invisible but occupies space)
I'm always visible
💡 display: none removes the element completely – it’s like it never existed.
visibility: hidden makes the element invisible but it still takes up space in the layout.

Other special values

  • list-item – adds a marker (like <li>)
  • table, table-cell, etc. – for table layouts
  • contents – element disappears, its children take its place
