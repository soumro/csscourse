Understanding vertical alignment in CSS Grid (and Flexbox)

💡 align-content moves the entire set of grid rows (tracks) vertically inside the container – only noticeable when total grid height is less than container height.
🧩 align-items aligns each item within its own grid cell vertically.

Aligns each item inside its own grid cell vertically. Items can have different heights.

align-items: center;
⚡ align-self does the same as align-items but on a single item (overrides the parent's align-items).

🔄 Flexbox Context

In Flexbox:

  • align-content aligns flex lines (when wrapping) vertically – only works with flex-wrap: wrap and multiple lines.
  • align-items aligns flex items along the cross axis (vertical when flex-direction: row).
