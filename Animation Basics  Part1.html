📖 Understanding @keyframes

@keyframes bounce {
  0% { transform: translateY(0); }
  50% { transform: translateY(-30px); }
  100% { transform: translateY(0); }
}

Keyframe selectors can be from / to (same as 0% / 100%) or any percentage. You can define multiple steps to create complex sequences.

💡 Animation Properties Cheatsheet:
animation-name – which keyframes to use.
animation-duration – how long one cycle lasts (s or ms).
animation-iteration-count – number of repeats or infinite.
animation-delay – wait before starting.
animation-direction – normal, reverse, alternate, alternate-reverse.
animation-timing-function – ease, linear, ease-in-out, etc.
animation-fill-mode – styles before/after animation.
