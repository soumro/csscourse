📖 Shorthand Syntax

animation: name duration timing-function delay iteration-count direction fill-mode play-state;
  • Only name and duration are required. The rest are optional and will use default values if omitted.
  • Default values: duration: 0s (no animation), timing-function: ease, delay: 0s, iteration-count: 1, direction: normal, fill-mode: none, play-state: running.
  • Order matters – the first time value is duration, the second is delay.
  • Example: animation: bounce 0.8s infinite alternate; (duration 0.8s, infinite loops, alternate direction).

✅ Valid Shorthand Examples

animation: bounce 0.6s infinite alternate;
animation: fadeScale 0.5s ease-out 0.2s forwards;
animation: moveRotate 1s linear infinite reverse;
animation: bounce 0.8s 3; (runs 3 times)

🎭 Multiple Animations (comma‑separated)

Multi

You can apply multiple animations to the same element by separating shorthand values with commas.

animation: bounce 0.6s infinite alternate, fadeScale 0.4s 1 forwards;
💡 The first animation listed runs first, but they start simultaneously. Use delays to sequence them.

💡 Tips & Best Practices

  • 🔹 Always include duration – otherwise animation won't run (defaults to 0s).
  • 🔹 Use descriptive keyframe names to keep your code readable.
  • 🔹 For complex animations, consider splitting into multiple keyframes or using separate properties for clarity.
  • 🔹 Comma‑separate multiple animations to combine effects (e.g., a continuous rotation + a one‑time fade‑in).
  • 🔹 Remember the order of time values: first is duration, second is delay.
  • 🔹 Omitted values take their default – e.g., animation: slide 2s; will run once with ease timing, no delay, etc.
