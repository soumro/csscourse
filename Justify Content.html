🎯 CSS `justify-content`

Align flex items along the main axis (Flexbox) or align grid columns along the inline axis (Grid).

1. Flexbox: justify-content

Item 1
Item 2
Item 3
justify-content: flex-start;
💡 In Flexbox, justify-content aligns items along the main axis (horizontal when flex-direction: row, vertical when flex-direction: column).

2. Grid: justify-content

1
2
3
4
justify-content: start;
📐 In Grid, justify-content aligns the entire grid horizontally within the container when the total grid width is less than the container width.
