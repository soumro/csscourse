🔄 Rearranging Items with CSS

Reorder, reposition, and override default document flow using order, grid-row/column, grid-area, and place-self.

1. Flexbox: order

Change the visual order of flex items without touching HTML. Default order = 0; lower numbers appear first.

Item 1 (order:0)
Item 2 (order:0)
Item 3 (order:0)
Item 4 (order:0)
.item { order: value; } /* default 0, negative allowed */
💡 order works in both Flexbox and Grid. Items are sorted by order value (ascending). Ties respect source order.

2. Grid: grid-row & grid-column

Place items anywhere on the grid by specifying start and end lines.

A
B
C
.item { grid-column: 1 / 3; grid-row: 2 / 3; }
🎯 Use grid-column: span 2 to make an item span multiple tracks. Values like 1 / 3 mean start at line 1, end at line 3.

3. Grid: grid-template-areas & grid-area

Name grid cells and assign items to those names – perfect for responsive reordering.

Header
Sidebar
Main Content
Footer
.container { grid-template-areas: 'header header' 'sidebar main' 'footer footer'; }
.item { grid-area: header; }
🧩 Try changing areas to 'main main' 'sidebar header' 'footer footer' to see items reposition instantly.

4. Single‑Item Alignment: place-self, align-self, justify-self

Reposition an individual item inside its grid cell without affecting others.

Normal
Place‑self: center
Normal
.item { place-self: center; } /* shorthand for align-self + justify-self */
⚡ place-self overrides align-items / justify-items on a per‑item basis.

🎯 Pro Tips: Combining Techniques

  • Use order for simple reordering in Flexbox/Grid.
  • Use grid-row / grid-column for explicit placement anywhere in the grid.
  • Use grid-template-areas for responsive reordering (e.g., mobile first).
  • Use place-self to fine‑tune a single item’s alignment inside its cell.
  • All these techniques keep the HTML clean and semantic – layout changes stay in CSS.
✨ Experiment above: change order numbers, drag items across grid cells, or modify template areas. Master these to build adaptive, reorderable layouts without JavaScript.
