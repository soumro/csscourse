🎯 justify-content vs justify-items

Understanding the difference in CSS Grid (and Flexbox context)

💡 justify-content moves the entire grid inside the container (only noticeable when grid is smaller than container).
🧩 justify-items aligns each item within its own grid cell horizontally.

📖 Explanation & Visual Examples

📦 justify-content

Aligns the entire grid horizontally within the container. Works when total grid width is less than container width.

justify-content: space-between;

📌 justify-items

A
B

Aligns each item inside its own grid cell horizontally. Items can have different widths.

justify-items: center;
⚡ justify-self does the same as justify-items but on a single item (overrides the parent's justify-items).

🔄 Flexbox Context

In Flexbox, there is no justify-items – only justify-content (aligns flex items along the main axis) and align-items (cross axis).
For individual item alignment, use align-self or margin: auto.
