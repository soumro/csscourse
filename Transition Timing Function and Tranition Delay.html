3. Understanding Timing Functions

🎯 Common Keywords

  • linear – constant speed
  • ease – starts slow, fast, ends slow (default)
  • ease-in – starts slow, ends fast
  • ease-out – starts fast, ends slow
  • ease-in-out – slow at both ends

📐 Custom Bézier Curves

cubic-bezier(x1, y1, x2, y2) gives full control. Values go from 0 to 1 for x, y can go outside for overshoot effects.

Example: cubic-bezier(0.68, -0.55, 0.265, 1.55) creates a "bounce" overshoot.

🪜 Step Functions

steps(number, direction) divides the transition into discrete steps.

steps(4, end) – 4 jumps, changes at the end of each step.

step-start = steps(1, start), step-end = steps(1, end).

✅ Best Practices

  • 🔹 Use ease for most UI transitions – it feels natural.
  • 🔹 linear works well for mechanical movements like loading bars.
  • 🔹 steps() is perfect for frame‑by‑frame animations (e.g., sprite sheets).
  • 🔹 Keep delays short (≤ 0.5s) for interactive elements to maintain responsiveness.
  • 🔹 Use custom cubic-bezier sparingly for distinctive branding or playful effects.
  • 🔹 Combine delay with multiple elements to create staggered, sequenced animations.
