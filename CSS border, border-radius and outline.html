📦 Border

border adds a line inside the margin, affects element size. Styles: solid, dashed, dotted, individual sides.

💡 Note: Border adds to total width/height. Use box-sizing: border-box to include padding & border in element's width.

⚪ Border‑Radius

border-radius rounds corners without changing layout. Values can be length or percentage.

🧪 Clipping content: Use overflow: hidden together with border-radius to clip background/content to rounded shape.

✏️ Outline

outline draws a line outside the border, doesn't affect layout. No individual sides, does NOT follow border-radius (always rectangular).

🔘 Focus outline (accessibility)

⚠️ Important: Outline does NOT respect border-radius (always sharp rectangle). Use outline-offset to push it outward. For better focus rings, consider box-shadow if rounded outline needed.

📊 Border vs Outline — Quick Comparison

FeatureBorderOutline
Affects layout / size✅ Yes (adds to width/height)❌ No
Individual sides (top/right/..)✅ Yes❌ No (always all sides)
Follows border-radius✅ Yes❌ No (always rectangular)
Supports offset❌ No✅ Yes (outline-offset)
