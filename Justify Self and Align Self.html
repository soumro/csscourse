💡 justify-self aligns horizontally (left/right) inside the grid cell.
🧩 align-self aligns vertically (top/bottom) inside the grid cell.
These properties override justify-items / align-items on the container.

⚖️ Container vs Individual Alignment

Default (center)
Overridden (start)
Default (center)
Overridden (end)
.container { justify-items: center; align-items: center; }
.item2 { justify-self: start; align-self: start; }
.item4 { justify-self: end; align-self: end; }
🎯 The container sets default alignment for all items. Individual *-self properties override them.

🔄 Flexbox Context

In Flexbox, align-self works exactly the same (overrides align-items on the cross axis). However, justify-self does nothing in Flexbox – use margin: auto instead.

center
flex-end

align-self: flex-start | center | flex-end | stretch;

📝 Shorthand: place-self

place-self: <align-self> <justify-self>; – set both at once.

place-self: center end
place-self: center end; /* align-self: center, justify-self: end */
