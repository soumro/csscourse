Controls how flex items shrink when there isn't enough space in the container.

📖 How `flex-shrink` Works

  • flex-shrink defines how much an item should shrink relative to others when there is negative space (overflow).
  • Default value is 1 – items are allowed to shrink.
  • If set to 0, the item will NOT shrink – it will overflow the container or cause a scrollbar.
  • Higher values cause the item to shrink more aggressively (e.g., flex-shrink: 2 shrinks twice as much as an item with 1).
  • Shrinking is proportional to the product of flex-shrink and the item's content size / flex-basis.
  • Together with flex-grow and flex-basis, it forms the flex shorthand: flex: <grow> <shrink> <basis>;
/* Example: first item never shrinks, middle shrinks twice as much */
.item1 { flex-shrink: 0; }
.item2 { flex-shrink: 2; }
.item3 { flex-shrink: 1; }

🧩 Flex‑Shrink in Context: The `flex` Shorthand

flex-shrink is part of the flex shorthand: flex: <flex-grow> <flex-shrink> <flex-basis>;

  • flex: 1; → flex-grow: 1; flex-shrink: 1; flex-basis: 0%;
  • flex: 0 1 auto; → default (no grow, can shrink, basis auto).
  • flex: 0 0 200px; → fixed width 200px, never grows or shrinks.
  • flex: 2 2 100px; → grow twice as much, shrink twice as much, start at 100px.
🔥 Common pattern: flex: 0 0 200px; to create fixed‑width elements that never resize.
