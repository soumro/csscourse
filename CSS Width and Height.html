📏 CSS Width & Height

Control element sizing with absolute, relative, and responsive units.

1. Basic Sizing

100x100
width: 100px; height: 100px;
150x80
width: 150px; height: 80px;
width: 50%
height: auto
50% of parent width
30vw x 30vh
viewport units
💡 auto height makes the element expand to fit its content. % width is relative to parent’s content width.

2. Box‑sizing: content-box vs border-box

content-box
width:200px + padding+border → actual width 250px
border-box
width:200px includes padding and border → content shrinks
🔄 Modern best practice: use * { box-sizing: border-box; } to make sizing predictable.

3. Min‑width, Max‑width, Min‑height, Max‑height

width: 50%
min:150px, max:250px
Resize window → width stays between 150px and 250px
min-height:80px, max-height:150px
Content expands until 150px, then scrolls.

📱 5. Viewport Units (vw, vh, vmin, vmax)

20vw x 10vh
20% of viewport width, 10% of viewport height
30vmin
30% of the smaller viewport dimension (great for squares)
🖥️ vw/vh are relative to the browser’s viewport size; useful for full‑page sections and responsive typography.

⚠️ Common Pitfalls & Best Practices

  • 🔹 Percentage height – only works if parent has an explicit height (or using flex/grid with align‑stretch).
  • 🔹 Inline elements – width/height are ignored; use display: inline-block or block.
  • 🔹 Box‑sizing – always set to border-box globally to avoid unexpected sizes.
  • 🔹 Max‑width on images – img { max-width: 100%; height: auto; } makes images responsive.
  • 🔹 Aspect‑ratio – use for videos, cards, and consistent shapes without JavaScript.
  • 🔹 Viewport units on mobile – be aware that vh can change when address bar appears; consider using dvh (dynamic viewport height) in modern browsers.
