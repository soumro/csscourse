📐 CSS Margin — The Ultimate Guide

One property to rule spacing outside elements: margin (top, right, bottom, left), auto, negative values, and collapsing behavior.

🔹 1. Margin basics & individual sides

Margin creates space outside an element's border, pushing other elements away. It does NOT affect the element's own background or content size.

margin: 20px (all sides)

margin: 20px → equal space around
⬅️ Parent boundary shows outer spacing

margin: 10px 40px

10px top/bottom, 40px left/right
vertical 10px · horizontal 40px

Individual sides

top:30px | right:10px | bottom:5px | left:50px
Each side can be controlled separately
💡 Shorthand syntax: margin: top right bottom left; (clockwise).
• 1 value → all sides
• 2 values → top/bottom & left/right
• 3 values → top, left/right, bottom
• 4 values → top, right, bottom, left

🎯 2. margin: auto — horizontal centering

Using margin-left: auto and margin-right: auto on a block element with a defined width centers it inside its parent.

🌟 This div has width: 70%; margin: 20px auto; → horizontally centered
Fixed width 300px + margin: 1rem auto;
⚙️ auto behavior: The browser calculates equal margins on left/right to fill the available space. Works for block elements with explicit width.

🔄 3. Negative margins — pull elements outside their natural flow

Negative margin values move the element opposite to the normal direction (e.g., negative top moves element upward, overlapping others).

🧪 Use case: Negative margins are powerful for creating overlapping UI effects, pulling elements out of containers, or fine-tuning layouts without position absolute.

📉 4. Margin collapsing — what every developer must know

Adjacent vertical margins of block elements often collapse into a single margin equal to the larger one.

Two adjacent blocks

First: margin-bottom: 30px
Second: margin-top: 20px
👉 Actual gap = 30px (largest wins) not 50px.

Parent & first/last child collapse

Child margin-bottom: 30px
Child margin-top: 40px
Between two children the margin collapses to 40px (max of 30 and 40). Also, parent may collapse with children if no border/padding separates them.
📚 Collapsing rules: Only vertical margins (top/bottom) collapse. Inline elements, floats, absolute positioning, flex/grid items do not collapse in the same way. Use padding or border to prevent parent-child collapse.
