📖 Understanding `flex-flow`

flex-flow is a shorthand that sets both flex-direction and flex-wrap in one declaration. It follows the pattern:

flex-flow: <flex-direction> <flex-wrap>;
  • If only one value is given, it applies to flex-direction and flex-wrap defaults to nowrap.
  • If two values are given, the first is flex-direction, the second is flex-wrap.
  • Allowed flex-direction values: row, row-reverse, column, column-reverse.
  • Allowed flex-wrap values: nowrap, wrap, wrap-reverse.
🎯 Using flex-flow reduces code duplication and makes your intent clearer – perfect for responsive layouts where direction and wrapping change at breakpoints.

📱 Responsive Flex‑flow with Media Queries

Change flex-flow at different screen sizes to completely reorganize your layout without touching HTML.

/* Desktop: horizontal row */
.container { flex-flow: row wrap; }

/* Mobile: vertical column */
@media (max-width: 600px) {
  .container { flex-flow: column nowrap; }
}
🧠 This is the power of flex-flow – you can redefine both direction and wrapping at once, making layouts incredibly adaptive.
