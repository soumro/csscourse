✨ CSS place-content

Shorthand for align-content and justify-content – perfect for centering and spacing in Grid & Flexbox.

💡 In Grid, place-content sets both align-content (vertical) and justify-content (horizontal) at once. The container has a fixed height to make alignment visible.

place-content: flex-start flex-start;
🔄 In Flexbox, place-content works when flex-wrap: wrap is enabled and there are multiple lines. It aligns the flex lines (align-content) and the flex items along the main axis (justify-content).

📖 Syntax & Usage

One value

place-content: center;

Sets both align-content and justify-content to the same value.

1
2

Two values

place-content: center space-between;

First = align-content, second = justify-content.

1
2
/* Examples */
place-content: center; /* center both axes */
place-content: start end; /* align: start, justify: end */
place-content: space-between stretch; /* align: space-between, justify: stretch (Grid only) */

📋 Common Values

Valuealign-contentjustify-content
start / flex-startAligns to topAligns to left
end / flex-endAligns to bottomAligns to right
centerCenters verticallyCenters horizontally
space-betweenEven space between rowsEven space between columns
space-aroundSpace around rowsSpace around columns
space-evenlyEqual space everywhereEqual space everywhere
🎯 Pro tip: Use place-content: center; to perfectly center a grid or flex container's content both horizontally and vertically – no more complicated margins!

🧩 Related Shorthands

  • place-content – aligns the entire grid/flex container (align-content + justify-content).
  • place-items – aligns items inside their cells (align-items + justify-items) – Grid only.
  • place-self – aligns a single item (align-self + justify-self) – Grid only.
