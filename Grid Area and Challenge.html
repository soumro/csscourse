🧩 CSS Grid Areas: The Ultimate Guide

Name grid cells and place items with grid-area and grid-template-areas – the most intuitive way to build complex layouts.

📐 1. grid-template-areas + grid-area

Define a visual map of your grid using ASCII art. Then assign each item to a named area.

Header
Sidebar
Main Content
Footer
grid-template-areas: 'header header'
              'sidebar main'
              'footer footer';
grid-template-columns: 1fr 2fr;
💡 The number of columns in your ASCII map must match grid-template-columns. Use a period (.) to leave an empty cell.

📏 2. grid-area with line numbers

grid-area: row-start / col-start / row-end / col-end; – a shorthand for placing an item by grid lines.

Item
grid-area: 2 / 2 / 4 / 4; /* spans rows 2-3, cols 2-3 */
🎯 Line numbers start at 1. Negative values count from the end. You can also use span (e.g., 2 / span 2 / 4 / span 2).

✨ Pro Tips

  • Use descriptive area names (e.g., "header", "sidebar", "content").
  • Empty cells are represented by a period . (e.g., 'header . sidebar').
  • You can rearrange the entire layout at different breakpoints using media queries – just change grid-template-areas!
  • Combine grid-area with grid-template-areas for responsive, semantic layouts.
  • Use grid-area line‑number syntax for precise control when areas aren't enough.
